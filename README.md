# WiestTech Website
Static website built from the HTML5 UP "Massively" template. Hosted on S3 + CloudFront (via GitHub Actions), with AWS Cognito for authentication.

## Layout
- `index.html` — Home (hero intro, featured post, services grid)
- `generic.html` — Generic page template
- `elements.html` — Elements reference page
- `assets/` — CSS, JS, and images

## Local development / preview
Because this is a static site, open `index.html` in VS Code with the **Live Server** extension to preview.
